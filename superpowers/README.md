# Engineering Work Records

This directory contains the planning and verification artifacts used to build
the IntelliKnow MVP. They are separated from `docs/` because they explain the
engineering process rather than how to operate the product.

- `plans/`: implementation increments and stabilization decisions; early files
  preserve the sequence as it was planned, while `plans/README.md` records the
  final status
- `test-plans/`: acceptance criteria written before implementation
- `evidence/`: channel acceptance inputs and recorded results
- `reports/`: focused engineering findings and calibration notes
- `TESTER-PROTOCOL.md`: independent verification workflow

The product contract and design decisions live separately in `openspec/`.
