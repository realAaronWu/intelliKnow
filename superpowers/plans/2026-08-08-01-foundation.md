# Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **No implementation code appears in this plan by project decision.** Each task states the behaviour to build and the contract to satisfy; the implementer writes both the failing test and the code. Test expectations live in `superpowers/test-plans/01-foundation-tests.md`. A clean tester validates against the spec afterwards — see `superpowers/TESTER-PROTOCOL.md`.

**Goal:** Build the configuration service, the AI provider abstraction, the test doubles every later plan depends on, and the database schema.

**Architecture:** One `config.yaml` validated by a pydantic model is the single source of truth for every tunable; secrets come only from the environment. All AI calls go through two protocols so backends swap by config and tests swap in deterministic fakes. Persistence is SQLite with an FTS5 virtual table for the keyword half of hybrid retrieval.

**Tech Stack:** Python 3.12, `uv`, pydantic v2, PyYAML, `anthropic`, `openai`, `sentence-transformers`, SQLAlchemy Core, `pytest`

## Global Constraints

- Python 3.12; dependencies via `uv`.
- Default LLM model `claude-opus-5` for both classification and generation.
- Default embedding model `all-MiniLM-L6-v2`, 384 dimensions, unit-normalized.
- Default confidence threshold 0.70; default relevance floor 0.45 (applies to the normalized cross-encoder score — see design.md § Reranking; the pre-reranker cosine value of 0.35 does not carry over).
- Secrets (`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `CREDENTIAL_ENCRYPTION_KEY`, `ADMIN_PASSWORD`) read from environment only, never written to `config.yaml`.
- Provider failures surface as `ProviderError` with category `timeout` | `rate_limit` | `auth` | `backend`; callers never see a backend-specific exception.
- L1 tests run with no network access.
- Every task: failing test first, watch it fail, minimal code, watch it pass, commit.

- Cross-field rule: `orchestrator.fallback_space` must name an existing intent space.
- `config.yaml` ships with the five default spaces and their keyword lists.
- `.env.example` lists only secrets, including the command to generate a Fernet key.

### Task 2: ConfigService

**Files:**
- Create: `app/config_service.py`
- Test: `tests/test_config_service.py`

**Interfaces:**
- Consumes: `app.config.AppConfig`, `load_config`
- Produces: `ConfigService.load(path) -> ConfigService`; property `current -> AppConfig`; `update(patch: dict) -> AppConfig`; `reload() -> AppConfig`.

**Behaviour to build:**
- `update` deep-merges a partial patch onto the file's current contents — siblings not named in the patch survive.
- Validation happens before any write. An invalid patch raises `ValueError` and leaves both the file on disk and the in-memory config untouched.
- Writes are atomic: temp file plus rename, so a crash mid-write cannot truncate the config. No temp file is left behind on either the success or failure path.
- The previous contents are preserved as a `.bak` sibling before each write.
- Applied changes are visible through `current` immediately, with no restart.

### Task 3: Provider protocols and error type

**Files:**
- Create: `app/providers/__init__.py`, `app/providers/base.py`
- Test: `tests/test_provider_base.py`

**Interfaces:**
- Produces:
  - `LLMResult(text: str, parsed: dict | None, model: str, input_tokens: int, output_tokens: int)` — immutable
  - `ProviderError(Exception)` with `.category: Literal["timeout","rate_limit","auth","backend"]` and constructors `timeout`, `rate_limit`, `auth`, `backend`
  - `LLMProvider` protocol — `complete(*, system: str, user: str, schema: dict | None = None, max_tokens: int = 1024) -> LLMResult`
  - `EmbeddingProvider` protocol — `embed(texts: list[str]) -> list[list[float]]`, property `dimension: int`
  - `normalize(vectors: list[list[float]]) -> list[list[float]]`

**Behaviour to build:**
- `LLMResult` is immutable — mutation raises.
- Each error constructor produces the matching category and preserves the message.
- `normalize` returns unit vectors and passes a zero vector through unchanged rather than dividing by zero.

### Task 4: Test doubles

**Files:**
- Create: `tests/doubles.py`
- Test: `tests/test_doubles.py`

**Interfaces:**
- Produces:
  - `FakeLLMProvider` — `expect_text(str)`, `expect_schema(dict)`, `fail_next(ProviderError)`, `.calls: list[dict]` recording `system`, `user`, `schema`, `max_tokens`
  - `FakeEmbeddingProvider(dimension: int = 8)` — `set_vector(text, vec)`, `.calls: list[list[str]]`

**Behaviour to build:**
- The LLM double returns queued responses strictly in order and raises a clear assertion when the queue is empty — an exhausted queue is a test bug and must not silently return a default.
- Every call is recorded so later plans can assert on prompt content (that keywords were included, that the channel profile was passed).
- `fail_next` raises once and then the queue resumes normally, so retry behaviour is testable.
- The embedding double derives vectors from a hash of the text: same text always yields the same vector, different texts differ, output is unit-norm, order and count are preserved. `set_vector` pins an exact vector so a test can place two chunks at a chosen similarity.

Every later plan's L1 tests import these. Their determinism is what makes score assertions possible at all.

### Task 5: Retry and timeout policy

**Files:**
- Create: `app/providers/retry.py`
- Test: `tests/test_provider_retry.py`

**Interfaces:**
- Produces: `with_retries(fn: Callable[[], T], *, max_retries: int, sleep: Callable[[float], None] = time.sleep) -> T`

**Behaviour to build:**
- Retries only `timeout` and `rate_limit`. `auth` and `backend` raise on the first occurrence — retrying a bad API key wastes the caller's latency budget for a guaranteed failure.
- Exponential backoff: 0.5s, 1.0s, 2.0s.
- Exhausted retries re-raise the last error with its category intact.
- `sleep` is injectable so tests never actually wait.

### Task 6: Concrete providers and factory

**Files:**
- Create: `app/providers/anthropic_llm.py`, `app/providers/openai_llm.py`, `app/providers/local_llm.py`, `app/providers/local_embedding.py`, `app/providers/openai_embedding.py`, `app/providers/factory.py`
- Test: `tests/test_anthropic_llm.py`, `tests/test_provider_factory.py`

**Interfaces:**
- Produces:
  - `AnthropicLLM(model, api_key, timeout_seconds, max_retries, client=None)` — the injectable `client` is what keeps these tests offline
  - `OpenAILLM`, `LocalLLM` — same constructor shape
  - `SentenceTransformerEmbedding(model_name, batch_size)`, `OpenAIEmbedding(model_name, api_key, batch_size)`
  - `build_llm_provider(cfg: AppConfig, *, role: Literal["classify","generate"] = "generate", env: Mapping[str,str] | None = None) -> LLMProvider`
  - `build_embedding_provider(cfg: AppConfig, env=None) -> EmbeddingProvider`

**Behaviour to build:**
- `role` is how one config yields two differently-modelled providers; later plans pass `role="classify"` for classification and `role="generate"` for answers.
- Every backend exception maps to the right `ProviderError` category before leaving the provider.
- A schema request asks the backend for structured output and returns a parsed object; output that does not parse raises `backend` rather than returning a broken result.
- On Claude Opus 5, request low effort to cut latency. Do **not** disable thinking — on this model that risks tool-call-as-text and thinking-tag leakage.
- Embedding providers batch at the configured size and return unit-normalized vectors.
- Factory failures are actionable: a missing key names the environment variable; an unknown provider name lists the supported values.

### Task 7: Database schema

**Files:**
- Create: `app/db.py`
- Test: `tests/test_db_schema.py`

**Interfaces:**
- Produces: `create_engine_for(path: Path)`, `init_schema(engine) -> None`, and table objects `documents`, `chunks`, `query_log`, `integrations`, plus the `chunk_fts` FTS5 virtual table.

**Behaviour to build:**
- Columns exactly as `design.md` § Data model.
- WAL journal mode enabled.
- Foreign keys enforced — SQLite disables them per connection by default, so the pragma must be set on connect or the cascade below silently does nothing.
- Deleting a document cascades to its chunks.
- `query_log` holds no foreign key to `documents`, so deleting a document does not erase the history of it having been used.
- `chunk_fts` is an FTS5 table over chunk text with BM25 ranking available.

### Task 8: Live provider smoke check

**Files:**
- Create: `scripts/smoke_provider.py`

**Behaviour to build:**
- One real call to the configured LLM backend with a schema, and one real embedding call; print the parsed object, the model id, and the vector dimension.
- Not part of any automated suite — it requires network and a key.

**Why this task exists:** Task 6's tests assert our own call shape against an injected stub. A stub cannot tell you the SDK accepts that shape. Without this, a wrong structured-output request shape stays hidden until plan 04's first real classification. Ten minutes here saves a confusing failure two plans later.
